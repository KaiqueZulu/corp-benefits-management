# Corporate Benefits Management (PL/SQL)

Este projeto simula um sistema de gestão de benefícios para colaboradores, desenvolvido em PL/SQL com foco em práticas corporativas e organização modular.

## Estrutura
- `docs/`: documentação, requisitos, modelagem
- `database/`: scripts DDL, DML, PL/SQL
- `tests/`: scripts de teste manuais

## Objetivo
Praticar desenvolvimento PL/SQL em um projeto robusto, com versionamento via Git e simulação de time real.
